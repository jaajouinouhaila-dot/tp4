# TP-4 — Creative Recipe Builder

Application React réalisée sans Vite, avec Create React App.

## Lancer le projet
1. Installer Node.js.
2. Ouvrir un terminal dans le dossier `tp-4`.
3. Exécuter `npm install`.
4. Exécuter `npm start`.

## Fonctionnalités
- Affichage des recettes sous forme de cartes
- Création et modification avec formulaire contrôlé
- Liste dynamique des ingrédients
- Import d'une image depuis l'ordinateur
- Duplication et suppression
- Recherche par nom et filtre par catégorie
- Pagination
- Aide intégrée

Les recettes sont conservées dans l'état React pendant l'utilisation de la page. Elles ne sont pas enregistrées dans une base de données.
